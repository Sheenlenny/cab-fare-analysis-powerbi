🚕 Cab Fare Analysis and Pricing
📌 Project Overview

This project focuses on analyzing cab ride data to identify fare trends and the key factors that influence pricing. The objective is to derive actionable insights that can help cab service providers optimize pricing strategies and improve revenue planning.

The analysis includes data cleaning, exploratory data analysis, feature engineering, and visual analytics to understand how distance and time impact cab fares.

📊 Dataset

Simulated cab ride dataset with 500+ records

Features include:

Distance traveled (in km)

Fare amount

Pickup time

Note: Mock data is used for demonstration purposes to showcase the analysis workflow and insights.

🛠️ Tools & Technologies

Python

Pandas & NumPy – data manipulation

Matplotlib & Seaborn – data visualization

Jupyter Notebook

🔍 Key Analysis Performed

Data cleaning and preprocessing

Feature engineering (extracting pickup hour)

Analysis of average fare by hour of the day

Relationship between distance traveled and fare amount

Fare distribution analysis

📈 Key Insights

Fare amounts tend to increase with distance traveled

Peak travel hours show higher average fares compared to off-peak hours

Fare distribution highlights variability influenced by time and distance

📷 Visualizations

The project includes:

Line chart showing average fare by hour

Scatter plot depicting distance vs fare

Histogram illustrating fare distribution
